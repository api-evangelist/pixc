# Pixc

> Pixc is an ecommerce enablement company that automates the visual busywork of running an
> online store. It ships five Shopify apps (photo resizing and AI framing, AI image editing,
> AI-generated alt text for SEO, AI lifestyle imagery, and visual merchandising of
> collections), runs a professional bulk product photo-editing service billed in prepaid
> image credits, and exposes a public REST API — the Pixc Public API — that lets a store or
> marketplace submit photos for optimization programmatically against reusable templates.
> Founded 2014, backed by 500 Global.

## The API in one paragraph

Base URL `https://dashboard.pixc.com/v1`. Authenticate with
`Authorization: Bearer ACCESS_TOKEN`, where the token comes from Account Settings > API
Access in the Pixc Dashboard. Three resources: **templates** (your photo standard —
background, border, shadow, output types, aspect sizes), **orders** (a batch of photo URLs
submitted against one template), and **webhooks** (callbacks when an order is created, its
status changes, or a download is generated). Create a template, POST an order with your
file URLs, then either wait for the `download_generated` webhook or poll
`GET /api/order/{orderId}/download`. Optimized photos come back within 24 hours as a .zip
or a list of URLs. Add the header `test: true` to any call to validate a payload without
spending image credits.

## Operations

Orders
- `apiListOrder` — GET /api/order — list orders (`api:order:view`)
- `apiAddOrder` — POST /api/order — submit photos, creating an order (`api:order:create`)
- `apiShowOrder` — GET /api/order/{orderId} — order details (`api:order:view`)
- `apiCancelOrder` — DELETE /api/order/{orderId} — cancel an order (`api:order:cancel`)
- `apiDownloadListOrder` — GET /api/order/{orderId}/download — downloads for an order (`api:order:view`)
- `apiImageListOrder` — GET /api/order/{orderId}/image — images for an order (`api:order:view`)

Templates
- `apiListTemplate` — GET /api/template (`api:template:view`)
- `apiAddTemplate` — POST /api/template (`api:template:create`)
- `apiShowTemplate` — GET /api/template/{templateId} (`api:template:view`)
- `apiUpdateTemplate` — PUT /api/template/{templateId} (`api:template:update`)
- `apiRemoveTemplate` — DELETE /api/template/{templateId} (`api:template:remove`)

Webhooks
- `apiListWebhook` — GET /api/webhook (`api:webhook:view`)
- `apiAddWebhook` — POST /api/webhook (`api:webhook:create`)
- `apiShowWebhook` — GET /api/webhook/{webhookId} (`api:webhook:view`)
- `apiUpdateWebhook` — PUT /api/webhook/{webhookId} (`api:webhook:update`)
- `apiRemoveWebhook` — DELETE /api/webhook/{webhookId} (`api:webhook:remove`)

## Events

Webhook types (enum on `WebhookObject.type`): `order_created`, `order_status_updated`,
`download_generated`. Pixc publishes no payload schema, signature scheme or retry policy for
these callbacks.
